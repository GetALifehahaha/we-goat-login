# Overview

We-Goat Authentication is a web-based final project focused on authentication systems, user security, and modern web application practices. The project demonstrates how secure login systems are designed, implemented, and protected against common authentication vulnerabilities.

The system was developed using:

- Django
- Django REST Framework (DRF)
- React

The application combines a RESTful backend architecture with a modern frontend interface to provide a secure and responsive user experience.

---

# Project Objectives

The main objectives of this project are:

- To understand how authentication systems work in modern web applications
- To implement secure user registration and login functionality
- To explore common authentication vulnerabilities and security risks
- To apply best practices in web security
- To integrate a React frontend with a Django REST API backend
